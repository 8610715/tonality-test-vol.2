# 調性判断テスト

和音進行を2つ聴き，同じコード進行かどうかを答える聴取実験のウェブアプリです。
スマートフォン・タブレット・PC のブラウザで動きます（音源は `index.html` に内蔵）。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | テスト本体（これ1つで動きます） |
| `gas/Code.gs` | 結果を Google ドライブに保存する Google Apps Script |

## 公開（GitHub Pages）

1. リポジトリの **Settings → Pages**
2. **Source**：`Deploy from a branch`，**Branch**：`main` / `/(root)` → **Save**
3. 数分後に表示される `https://<ユーザー名>.github.io/<リポジトリ名>/` が参加者用のURLです

## 実験の流れ

1. 実験者：右上の「設定」→ 条件を確認 →「設定を確定して参加者画面へ」
2. 参加者：参加者IDを入力 → 進め方を読む →「スタート」
3. 終了すると結果は自動で送信されます（失敗した場合は端末に保管され，設定画面の「未送信データを送信」で再送できます）
4. 次の参加者：「設定」→「設定を確定して参加者画面へ」で ID 入力画面に戻ります

学習群などの情報は参加者IDに含めてください。

## 結果の保存（Google Apps Script）

1. https://script.google.com で新しいプロジェクトを作り，`gas/Code.gs` の内容を貼り付けて保存
   （`FOLDER_ID` は保存先のドライブフォルダのIDです）
2. 関数「setup」を選んで実行し，権限を承認
3. **デプロイ → 新しいデプロイ → ウェブアプリ**（実行：自分／アクセス：全員）
4. 発行された `…/exec` のURLを，テストの設定画面「送信先URL」に入力して「接続テスト」

保存先フォルダには，集計スプレッドシート（`trials` / `summary` シート）とセッションごとのCSVが作られます。
